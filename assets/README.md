# /assets

Static brand and content assets not tied to a specific app bundle: logo source files, drill demonstration media referenced by the `drills` table ([/docs/04-database.md](../docs/04-database.md) §1, `media_url`), and marketing-site imagery.

Empty until brand/content production begins. Large binary assets (video/image) that end up player-facing in production are expected to move to object storage rather than staying in the git repository long-term — this directory is for source/working files and small reference assets.
